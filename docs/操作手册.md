# 藏册 Catalogue 操作手册

适用版本：V1.0

## 1. 首次使用

1. 在浏览器打开部署工程师提供的地址，例如 `https://192.168.1.20:8443`。
2. **解锁**：输入主口令。主口令只有您本人知道，用来解密全部档案。
   - 主机每次重启后，都需要重新解锁一次。
   - 主口令遗失后数据**无法找回**，请线下妥善保管。
3. **登录**：输入您的账号和密码。

### 添加到手机主屏幕（可选）

| 系统 | 操作 |
| --- | --- |
| iPhone | 用 Safari 打开系统地址，点"分享" → "添加到主屏幕" |
| Android | 用 Chrome 打开，点菜单 → "添加到主屏幕" |

添加后桌面上会多一个图标，点开即是系统网页，相当于书签，不需要安装任何 App。手机必须和主机在同一个局域网内；如果选配了远程访问，则需要先开启 Tailscale。

### 电视上观看展览

- **电视自带浏览器**：打开系统地址，用"只读访客"账号登录，进入"展览"点"放映"。
- **投屏**：电视浏览器不好用时，可以在手机或 iPad 上打开放映，再用 AirPlay 或 Chromecast 投到电视。

## 2. 藏品档案

- **新建藏品**：在"藏品档案"页点"新建藏品"，选择分类后会出现该分类的专属字段，例如老酒的生产年份、茅台标识，名表的机芯、序列号。编号可以留空，系统会自动生成，如 `LIQ-00001`。
- **上传档案文件**：在藏品详情页先选择文件类型，再选择文件。
  - 文件类型：实拍图、细节防伪图、鉴定报告、合同、拍卖凭证、保险协议。
  - 支持一次选多个文件。
  - 手机上可以直接点"拍照"。
- **识别内容**：上传后系统会在本机自动识别文字，并对鉴定报告等文件生成摘要。点文件旁的"识别内容"即可查看。
- **记录盘点和保养**：在详情页点"记录 → 今日已盘点 / 今日已保养"，提醒会随之重新计算。

## 3. AI 档案检索

在"AI 检索"页直接提问。例如：

- "我的劳力士放在哪里？"
- "哪些藏品的保险快到期了？"
- "翡翠手镯的鉴定机构是哪家？"

使用规则：

- AI 只根据您录入的信息和上传的档案回答，并列出参考来源，点击来源可以跳到对应藏品。
- 找不到依据时，会直接回答"档案中无相关记录"。
- 不回答估值、行情和真伪问题。
- 在某件藏品的详情页点"就此藏品提问"，就只在这件藏品的档案范围内检索。

AI 结果仅作档案查阅参考，不具备鉴定、评估的法律效力。

## 4. 提醒

系统每天 8:00 自动检查以下三类情况，提醒会出现在"提醒"页，导航栏会显示未读数：

| 类型 | 触发条件 |
| --- | --- |
| 保险到期 | 默认在到期前 30 天、7 天和到期当天各提醒一次 |
| 保养到期 | 上次保养日加上保养周期，默认提前 7 天提醒 |
| 长期未盘点 | 默认超过 180 天未盘点 |

藏家可以在"系统设置"中修改这些规则，也可以配置邮件通知。

## 5. 账号与权限（藏家本人）

| 能力 | 藏家本人 | 助理 | 只读访客 |
| --- | :-: | :-: | :-: |
| 查看藏品、预览图片、AI 检索 | ✓ | ✓ | ✓ |
| 新增、编辑藏品，上传文件 | ✓ | ✓ | |
| 下载原件 | ✓ | ✓ | |
| 删除藏品 / 删除鉴定报告、合同等核心档案 | ✓ | | |
| 导出全量台账 | ✓ | | |
| 导出保险清单、统计表 | ✓ | ✓ | |
| 账号管理、审计日志、系统设置 | ✓ | | |

- **新建账号**：在"账号管理"中点"新建账号"，选择角色并设置初始密码。
- **强制下线**：可以让某个账号的所有设备立即下线，也可以只下线某一台设备。手机丢失时请立即操作。
- **停用账号**：停用后该账号无法登录，所有设备同时下线。

## 6. 数据导出

在"数据导出"页可以导出 Excel 文件。

导出的文件是**明文**，请妥善保管，不要通过微信、邮件等第三方渠道传输。每次导出都会记入审计日志。

## 7. 审计日志（藏家本人）

所有关键操作都有记录，可以按账号、操作类型和日期筛选，展开某一行可以查看详情。记录的操作包括：

- 登录和登录失败
- 新增、修改、删除，修改会精确到字段
- 上传、预览、下载
- 每一次 AI 提问和回答
- 导出
- 越权尝试

## 8. 锁定系统

在"系统设置 → 系统安全"中点"立即锁定系统"，内存中的密钥会被清除。

外出或长时间不使用时，建议锁定系统。再次使用时，需要重新输入主口令解锁。

## 9. 常见问题

**AI 显示"未就绪"？**
本地 AI 服务（OCR、向量模型、大模型）还没有启动。档案管理不受影响，AI 检索会暂时退化为关键词匹配。请联系运维人员处理。

**手机打不开系统？**

- 确认手机和主机连在同一个 Wi-Fi 下。
- 如果是远程访问，确认 Tailscale 已经开启。
- 如果主机的 IP 地址变了，请联系运维人员在路由器上为主机固定 IP。

**忘记登录密码？**
请藏家本人在"账号管理"中重置。如果是藏家本人忘记了密码，请联系运维人员协助。

**忘记主口令？**
无法找回，数据也无法解密。这是"服务商不持有密钥"这一设计的必然结果。
