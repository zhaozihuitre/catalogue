# 藏册 Catalogue 隐私安全说明书

适用版本：V1.0

本说明面向藏家本人及其顾问，说明系统如何保护藏品资料，以及哪些风险需要藏家自行承担。

## 1. 数据存放在哪里

所有业务数据都只存放在您自有的设备上（MacMini、NAS 或您名下的云服务器），包括：

- 藏品信息
- 照片、鉴定报告、合同、凭证
- AI 识别出的文字、向量索引
- 审计日志

系统**没有**以下任何能力：

- 上传到第三方云端的通道
- 埋点和统计
- 后台静默上报
- 远程遥测
- 调用外网大模型 API

OCR、向量化和大模型推理全部在本机完成。代码会校验 AI 服务地址，只允许连接本机或内网地址。

## 2. 加密方式

| 对象 | 方式 |
| --- | --- |
| 数据库（藏品、账号、AI 索引、审计日志） | SQLCipher 整库加密（AES-256） |
| 照片和文档原件，以及缩略图、预览图 | 每个文件使用独立随机密钥，AES-256-GCM 加密；文件密钥再由主密钥包裹（信封加密） |
| 落盘文件名 | 随机 UUID，看不出与藏品的对应关系 |
| 网络传输 | 云服务器部署强制 HTTPS。家庭内网可选 HTTP（见第 6 节第 7 条）。会话 Cookie 设置为 HttpOnly、SameSite=Strict，HTTPS 下另加 Secure |
| 登录密码 | Argon2 哈希存储 |

### 密钥来源

主密钥由您设定的**主口令**经 scrypt 派生得到，再分别派生出数据库密钥和文件密钥。

- 口令和密钥**只存在于主机内存中**，从不写入磁盘。
- `keystore.json` 文件只保存盐和算法参数，不含任何密钥。
- 服务商和运维人员**不持有**主口令，也无法解密您的资料。
- 主机重启或执行"锁定系统"后，内存中的密钥会被清除，需要您重新输入主口令。

### 与产品需求文档的差异

PRD 中写的向量库是 Chroma。但 Chroma 落盘时是明文，会把档案文字以未加密的形式写到磁盘上。

因此本系统把向量和原文一起存放在 SQLCipher 加密库中，与其他数据受同等保护。对于私人收藏的规模，检索速度没有影响。

## 3. 访问控制与审计

- **三级权限**：藏家本人、助理、只读访客。权限由服务端强制校验，不依赖页面上的按钮显隐。
- **只读访客的限制**：只能看压缩后的预览图和识别出的文字，无法下载原件。
- **核心档案的保护**：鉴定报告、合同、拍卖凭证、保险协议只能由藏家本人删除。
- **设备管理**：藏家可以随时查看所有在线设备并强制下线。修改密码、停用账号或调整角色时，相关设备会自动下线。
- **登录防护**：登录和解锁接口有频率限制。登录失败会记入审计日志。
- **审计日志**：在数据库层面只能追加，不能修改或删除。AI 问答的问题、回答和引用来源都会完整记录。

## 4. 手机端

手机只是访问入口，不运行任何 AI 模型，也不保存档案：

- 接口数据、照片和文件全部设置为**禁止缓存**，系统不做任何离线缓存。
- 退出登录时，会清空本地存储和缓存。
- 手机丢失时，请立即在"账号管理"中强制下线该设备。

## 5. AI 的边界

- AI 只能依据您的档案作答。检索不到依据时，直接回答"无记录"，不会让大模型自由发挥。
- 估值、行情、真伪类问题会被规则直接拦截，不送给大模型。
- 每条回答都附带固定的免责声明。

本地大模型仍然可能误读原文，重要信息请以档案原件为准。

## 6. 需要您知悉的风险

1. **主口令遗失 = 数据永久无法解密。** 请线下妥善保管，并考虑在保险柜中留存一份。
2. **备份由您自行负责。** 系统不做任何自动云备份。请定期把数据目录拷贝到您自己的离线介质；备份文件本身是加密的。
3. **导出的 Excel 是明文。** 请妥善保管，不要通过第三方即时通讯工具或邮件传输。
4. **MacMini 和 NAS 版本依赖本地供电与网络。** 断电或断网时系统无法访问；主机重启后需要重新解锁。
5. **远程访问是增值选项。** 开启 Tailscale 会引入网络侧风险，默认交付为纯内网模式。系统禁止直接做公网端口映射。
6. **云 ECS 版本的局限。** 云厂商在技术上可以访问运行中服务器的内存。加密能防止磁盘、快照层面的泄露，但无法防范云厂商在运行时访问。对隐私要求更高时，请选择 MacMini 或 NAS 版本。
7. **家庭内网 HTTP 模式。** 为了让电脑、手机、电视都能直接打开网址、无需安装证书，MacMini 和 NAS 版本可以在家庭内网用 HTTP 提供服务。此时同一 Wi-Fi 内的设备在技术上可以截获登录密码和档案内容。因此：
   - 家庭 Wi-Fi 请设置强密码。
   - 访客请连接路由器的"访客网络"，不要连主网络。
   - 远程访问必须通过 Tailscale，其流量本身是端到端加密的。
   - 对网络安全要求更高时，可以改用 HTTPS 部署，但需要在每台访问设备上安装证书，电视上通常无法完成。
8. **服务商的责任范围。** 服务商只提供系统部署与运维，不对藏品真伪、价值或鉴定结论承担任何责任。

## 7. 运维人员行为规范

- 只在您授权的情况下登录主机进行维护。
- 不索取、不记录主口令和您的登录密码。初始化时，主口令由您本人输入。
- 不复制数据目录。如需排查问题，只查看服务日志；日志中不包含档案内容和 Cookie。
